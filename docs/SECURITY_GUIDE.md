# Безопасность в вайб-кодинге — гигиена с первого дня

Простые правила, которые экономят вам потом часы (или карьеру).

## Правило 5 НЕ

1. **НЕ** вставляй реальные пароли, токены, API-ключи в чат с ИИ — даже «для теста».
2. **НЕ** ставь npm-пакет без проверки имени, автора и количества загрузок.
3. **НЕ** запускай PowerShell/curl-команды из непонятного источника (особенно из YouTube).
4. **НЕ** давай агенту write-доступ в production без человеческого ревью.
5. **НЕ** принимай diff, который не понимаешь.

## Секреты

- Все ключи и пароли — только в `.env`, который в `.gitignore`.
- Рядом всегда `.env.example` с пустыми ключами — для других людей.
- Перед `git push` — глазами просматриваем `git diff`.
- Если секрет случайно попал в репо — **отзывайте у сервиса немедленно**.
  История Git сохранит его навсегда, даже если удалить файл.

## Supply-chain — поддельные CLI и пакеты

В 2025 году были задокументированы реальные атаки:

- Вредоносный npm-пакет, маскировавшийся под «Codex UI», крал OpenAI-токены.
- Похожие кампании были вокруг «ранних версий Gemini CLI».

Правила выживания:

- Ставьте инструменты **только с официальных страниц вендора**.
- Проверяйте имя пакета: типосквоттинг (`reactt`, `vuejs-lib`, `geminii`) — частый трюк.
- Смотрите на дату публикации, число загрузок, активность GitHub.
- Если в YouTube кто-то «нашёл секретную CLI» — почти наверняка фейк.

Полезный инструмент: [Snyk Advisor](https://snyk.io/advisor/) — оценка
популярности и безопасности любого npm-пакета.

## XSS — главная дыра vanilla JS

Никогда не вставляйте пользовательский ввод в `innerHTML` без escape:

```js
function escapeHtml(s) {
  return s.replace(/[&<>"']/g, (c) => ({
    '&': '&amp;', '<': '&lt;', '>': '&gt;',
    '"': '&quot;', "'": '&#39;'
  }[c]));
}

container.innerHTML = items.map(item => `
  <span>${escapeHtml(item.name)}</span>
`).join('');
```

Альтернатива — `textContent` вместо `innerHTML` для текстовых вставок:

```js
const span = document.createElement('span');
span.textContent = item.name;  // браузер сам экранирует
container.appendChild(span);
```

## LocalStorage — что можно и нельзя

Можно:

- Состояние UI (тёмная тема, развёрнутые секции).
- Локальный кеш данных, которые не страшно потерять.

Нельзя:

- Пароли, токены, любые секреты (всё в `localStorage` доступно любому JS на странице).
- Чужие персональные данные.

Всегда оборачивайте чтение в `try/catch` — LocalStorage может быть выключен
или переполнен:

```js
let data = [];
try {
  data = JSON.parse(localStorage.getItem('habits')) || [];
} catch {
  data = [];
}
```

## Agent permissions — минимально необходимый доступ

- На обучении агент работает в платформе, доступа к вашим файлам нет.
- После курса в Antigravity/Cursor/Claude Code: давайте агенту доступ
  только к нужным папкам. Не открывайте корень диска.
- Запросы агента на установку пакета или запуск shell — **всегда читайте**
  перед подтверждением.
- В Antigravity Manager пользуйтесь Pause/Resume — это место осознанности.

## Безопасность ссылок в курсе

В библиотеке ресурсов курса все ссылки внешние, открываются в новой
вкладке с `rel="noopener noreferrer"`. Если добавляете новые ресурсы —
проверьте, что URL ведёт на официальный сайт, а не на агрегатор и не на
короткую ссылку.
