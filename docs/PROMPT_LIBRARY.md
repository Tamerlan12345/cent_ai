# Библиотека промптов — Centras CodeAI

Готовые шаблоны на все недели курса. Копируйте, заполняйте `[квадратные
скобки]`, отправляйте в Antigravity (Editor или Manager) либо в любой
другой агент. На платформе курса часть из них уже встроена в «Шпаргалку
промптов» внутри Monaco-песочницы.

---

## Неделя 1 — мышление и выбор идеи

### Промпт 1.1 · Генерация идей MVP
```text
Ты — продакт-ментор и наставник по вайб-кодингу.
Я учусь делать первый MVP в Google Antigravity.
Сфера моего интереса: [укажите свою].
Я НЕ программист, но у меня есть IDE с агентом.

Сгенерируй 10 идей мини-приложений, которые:
- решают одну конкретную боль,
- собираются на HTML/CSS/JS + LocalStorage,
- не требуют бэкенда, авторизации, платежей,
- я могу показать другу за 60 секунд.

Для каждой идеи укажи:
- кто пользователь,
- какую боль решает,
- 3 главные функции MVP,
- что НЕ войдёт в MVP,
- сложность по 10-балльной шкале.
```

### Промпт 1.2 · Сборка Vibe Coding Canvas интервью-стилем
```text
Я выбрал идею: [одна строка].
Помоги мне заполнить Vibe Coding Canvas.

Сначала задай 10 уточняющих вопросов:
- кто пользователь,
- какая боль,
- что он делает сейчас,
- какие шаги ждёт в моём приложении,
- какие 3 функции войдут в MVP,
- что НЕ войдёт,
- какие данные хранятся,
- какие экраны нужны,
- какие риски,
- что ты как агент делаешь, что я как человек.

После моих ответов собери Canvas в Markdown.
Не пиши код — это только продуктовый этап.
```

## Неделя 2 — контекст, AGENTS.md, Git

### Промпт 2.1 · Сгенерировать AGENTS.md под мой проект
```text
Ты — Senior Lead Architect.
Я пишу AGENTS.md для моего MVP в Antigravity.
Канва моего проекта: [вставьте Canvas].
Стек: HTML/CSS/JS + LocalStorage, без бэкенда.

Сгенерируй AGENTS.md с разделами:
Project, Stack, Commands, Rules, Architecture, Done criteria.

Ограничения:
- Без React/Vue/Tailwind, без бэкенда, без секретов.
- Маленькие diff.
- Никаких выдуманных команд — у нас платформа курса, см. Commands.
```

### Промпт 2.2 · PR-summary по моему изменению
```text
Я внёс изменения в проект. Вот diff: [вставьте].
Сделай PR-summary по нашему шаблону:
- Что сделано (одно предложение)
- Почему
- Как проверить (3 шага)
- Скриншоты/артефакты (что я должен приложить)
- Риски
- Чек-лист
```

## Неделя 3 — Antigravity workflow и сборка MVP

### Промпт 3.1 · Шаблон задачи для агента
```text
## Task
[Одно предложение, что сделать]

## Context
- Прочитай: @AGENTS.md, @PROJECT_BRIEF.md, @styles.css
- Опирайся на: [конкретный файл/функция]

## Constraints
- Менять только: [список файлов]
- Не трогать: [список файлов]
- Без новых библиотек
- Стиль кода — как в AGENTS.md

## Done
- [пункт 1]
- [пункт 2]
- Превью открывается без ошибок
- Артефакт-скриншот приложен
```

### Промпт 3.2 · Stop-Snapshot-Reproduce-Isolate (когда агент пошёл циклом)
```text
СТОП. Останови генерацию кода.

Я сделал снапшот текущего состояния.
Воспроизведение: [точные шаги, что я сделал].
Ошибка: [текст ошибки или поведение].

Теперь объясни текстом, почему функция X получает undefined.
Назови файл, функцию и причину.
Предложи 2 варианта исправления.
Код пока не меняй. Жду моего выбора.
```

### Промпт 3.3 · Project X-Ray (изучаю чужой проект)
```text
Ты — Senior Software Architect и преподаватель.
Изучи проект и ничего не меняй. Сделай рентген:

1. Определи стек.
2. Найди точку входа.
3. Опиши структуру папок.
4. Найди главные сущности данных.
5. Найди маршруты и страницы.
6. Найди источники данных и API.
7. Найди, как запустить проект.
8. Найди риски: безопасность, дубли, устаревшие практики.
9. Составь карту проекта для новичка.
10. Предложи 5 безопасных первых задач для улучшения.

Формат ответа:
- Краткое резюме
- Архитектурная карта
- Таблица файлов
- Что можно менять безопасно
- Что нельзя трогать без понимания
- Первые 5 задач
```

## Неделя 4 — QA, безопасность, защита

### Промпт 4.1 · Red Team (вредный QA)
```text
Ты — вредный QA и security reviewer.
Твоя задача — сломать мой MVP.

Проверь @index.html, @styles.css, @main.js:
- XSS через innerHTML
- Пустые поля, длинные строки, спецсимволы
- LocalStorage corruption (битый JSON, переполнение)
- Быстрые повторные клики
- Отсутствие интернета (если есть fetch)
- Мобильная вёрстка (ширина 375)
- Доступность: контраст, alt, label, focus

Сначала таблица:
Проблема | Как воспроизвести | Риск | Как исправить

Код не меняй. Сначала анализ.
```

### Промпт 4.2 · Подготовка защиты на 3 минуты
```text
Я защищаю проект «[название]» на 3 минуты.
Подготовь:
1. Тексты 5 слайдов (по 30–40 секунд каждый).
2. Полную речь докладчика.
3. Список 5 вопросов комиссии и шаблоны ответов.

Контекст: @PROJECT_BRIEF.md, @TEST_PLAN.md, @AGENTS.md
Ссылка на внутренний деплой: /preview/[id]

Ограничения:
- Без жаргона, понятно нетехническому слушателю.
- Честно про роль агента и роль человека.
- Без громких революционных слов.
```

## Универсальные

### Объясни код (Mentor mode)
```text
Объясни мне этот фрагмент кода строка за строкой, как новичку:
[ВСТАВЬ КОД]
Назначение / поток данных / один риск / одно простое улучшение.
Код не меняй.
```

### Помоги починить ошибку
```text
У меня возникает ошибка: [ВСТАВЬ ОШИБКУ]
Объясни простым языком:
- в каком файле и строке причина,
- почему это происходит,
- как исправить минимальным diff.
Сначала анализ, потом код.
```

### Рефакторинг без изменения поведения
```text
Рефакторинг @[файл]. Поведение не менять.

Что улучшить:
- Удалить мёртвый код
- Вынести магические числа в константы
- Дать понятные имена
- Добавить JSDoc к ключевым функциям

Ограничения:
- Никакой новой логики
- Не подключать библиотеки
- Не менять публичные API
- Маленький diff
```
