# Руководство куратора — Centras CodeAI

## Что делает куратор

1. Управляет расписанием когорты — открывает по неделям контент для учеников.
2. Раздаёт **машинные квоты** на песочницу (RAM, CPU, число `/preview/:id`, длительность сессии).
3. Проверяет сданные работы и оставляет комментарии в кабинете.
4. Помогает ученикам с защитой MVP.

## Кабинет куратора — `/teacher`

Доступен пользователям с ролью `teacher` или `admin`.

### Расписание когорты
- В сайдбаре выберите «Текущая открытая неделя».
- Для учеников модули новее этой недели будут заблокированы (видна табличка
  «Модуль заблокирован куратором»).

### Машинные квоты
- Выберите ученика в выпадающем списке.
- Задайте RAM (МБ), CPU (%), максимум одновременных деплоев и длительность
  сессии превью в секундах.
- В поле «Заметка для ученика» можно объяснить, почему лимит такой.
- Кнопка «Сохранить квоту» — обновит локальное хранилище платформы.
  Ученик увидит новые значения сразу при открытии практики.

> Сервер платформы один и без Docker. Квоты — административные:
> мы не зажимаем процессы изоляцией, а **показываем ученику честно**
> границы, в которых он работает. Это и педагогически правильно
> (учит работать в реальных ресурсах), и не требует контейнеризации.

### Сданные работы
- Таблица всех `submissions`. Кнопка «Детали» открывает drawer с кодом
  ученика, рубрикой и ревью ИИ.

### Внутренние деплои ученика
- Ниже квот — список активных `/preview/:id` выбранного ученика.
- Кнопка корзины — удалить деплой (например, если ученик упёрся в лимит,
  но старая версия уже не нужна).

## Перенос контента курса в Supabase

По умолчанию контент берётся из `src/content/courseData.ts`. Для боевого
использования перенесите модули в Supabase (`courses`, `course_modules`,
`module_blocks`) — `contentService.ts` сам подхватит опубликованный курс
со slug `vibe-coding-basics`.

## Чек-лист на старте когорты

- [ ] В Supabase созданы `cohort_id = 1` и активная неделя = 1
- [ ] Каждому ученику задана базовая квота (по умолчанию: 512 МБ / 25% / 3 деплоя / 5 мин)
- [ ] Контент `courseData.ts` проверен (выходные года в слайдах, ссылки в библиотеке)
- [ ] Открыт `/tour` — ученики прошли онбординг
- [ ] Зафиксирован график защит финального MVP
