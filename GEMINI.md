# GEMINI.md — Centras CodeAI

Контекстный файл для **Gemini CLI** и режима Gemini в Antigravity.

## Project

Учебная платформа курса «Вайб-кодинг 2026», русскоязычная аудитория без
программистского бэкграунда. Базовый workflow курса — Google Antigravity
(см. `AGENTS.md` для полной карты).

## Focus

Используй Gemini как **второго ревьюера** и инструмент для большого
контекста. Сильные стороны под этот проект:

- Поиск устаревших AI-инструкций в контенте курса.
- Проверка ссылок в `resourceLinks` (нет `url:#`, нет битых).
- Согласованность типов слайдов в `courseData.ts` со `Slide` из `types.ts`.
- Логические дыры в основном сценарии MVP трекера.
- Доступность UI: контраст, фокус, ARIA, мобильная вёрстка.

## Style

- Ответы на русском.
- Сначала таблица проблем: `Проблема | Файл/строка | Риск | Как исправить`.
- Минимальные правки, без переписывания всего модуля.
- Если предлагаешь новую зависимость — обоснуй и предложи альтернативу.

## Don't

- Не предлагай React-альтернативы текущему контенту (он специально на
  HTML/CSS/JS для упрощения обучения).
- Не меняй язык контента с русского на английский.
- Не трогай существующие комментарии без явного запроса.
- Не вводи новые слайды и практики, если не просят.
